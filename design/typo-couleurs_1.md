# Typographie et couleurs — 3 maquettes BoardMatch

## 1. Sobre

**Police** : mixte
- Titre ("BoardMatch") : -apple-system, "Helvetica Neue", Arial, sans-serif
- Reste du texte (filtres, noms, meta, prix) : "Space Mono", monospace

**Couleurs**
| Usage | Couleur |
|---|---|
| Fond | `#FFFFFF` |
| Texte principal | `#1A1A1A` |
| Texte secondaire (meta) | `#8A8A8A` |
| Bordures | `#E5E5E5` / `#EEEEEE` / `#CFCFCF` |

**Tailles clés**
- Logo (Helvetica Neue) : 15px, majuscules, letter-spacing 0.12em, graisse 600
- Nom produit (Space Mono) : 14px, graisse 700
- Meta (Space Mono) : 11px
- Prix (Space Mono) : 13px, graisse 700
